# Token Launch Radar

An offline token launch intelligence dashboard built for the make.fun Token Launch Radar competition.

[![make.fun Competition](https://make.fun/badge/token-radar-01.svg)](https://make.fun/c/token-radar-01)
[![Rank](https://make.fun/badge/token-radar-01/SUSLANDEX/token-launch-radar/rank.svg)](https://make.fun/c/token-radar-01)
[![Reward](https://make.fun/badge/token-radar-01/SUSLANDEX/token-launch-radar/reward.svg)](https://make.fun/c/token-radar-01)

## Features

- Protocol rankings and launch opportunity signals
- Interactive dashboard with search, filters and sorting
- Token launch watchlist and recorded-token protocol coverage
- Farming plans for tracked protocols
- Deterministic offline execution
